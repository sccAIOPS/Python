## Quick Reference

| Algorithm | Time Complexity | Use Case |
|-----------|-----------------|----------|
| Euclidean GCD | O(log min(a,b)) | Finding GCD |
| Sieve of Eratosthenes | O(n log log n) | Finding all primes up to n |
| Miller-Rabin | O(k log³ n) | Primality testing |
| Newton-Raphson | O(log n) iterations | Root finding |
| FFT | O(n log n) | Polynomial multiplication |
| Matrix Exponentiation | O(k³ log n) | Linear recurrences |
